## ChatGPT Go 是什么？先搞清楚买的是什么

按官方帮助文档的定义，ChatGPT Go 是一个低价订阅档，在免费版全部能力的基础上，把几项高频功能的额度放大：

- 更多消息、文件上传和图像生成额度，官方给出的数字是免费版的 10 倍
- 更长的记忆和上下文窗口，跨对话记住更多细节
- 可以使用 projects、tasks、自定义 GPT 和 Library，受功能可用性和存储限制

推理方面，Go 用户可以在网页端和手机 App 使用 Think 模式（手机端从 + 菜单进入），当前帮助文档写明它基于 GPT-5.6 Luna；GPT-5.6 Sol 和 4o 这类旧模型不在 Go 的范围内。模型阵容会随版本更新变化，下单前以页面实际显示为准。

两个容易忽略的限制：订阅不含 API 额度，API 独立计费；部分更高级的产品功能仍然要求 Plus 或更高档位。
